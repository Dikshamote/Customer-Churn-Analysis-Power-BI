# 📊 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn data using **Microsoft Power BI** to understand customer retention, churn patterns, and factors associated with customer churn.

## 🎯 Business Objectives

- Measure overall customer churn
- Analyze churn across customer segments
- Identify patterns based on tenure and contract type
- Analyze monthly and total charges
- Compare churn across payment methods
- Identify areas where customer retention can be improved

## 🛠️ Tools & Techniques

- Microsoft Power BI
- Power Query
- Data Cleaning & Transformation
- Data Modeling
- DAX
- Interactive Dashboard
- Data Visualization

## 📂 Dataset

The dataset contains customer-level information including:

- Customer ID
- Tenure
- Monthly Charges
- Total Charges
- Contract
- Payment Method
- Churn Status

## 🔍 Analysis Performed

- Overall churn analysis
- Churn by contract type
- Churn by tenure
- Churn by monthly charges
- Churn by payment method
- Customer segmentation
- KPI analysis and dashboard visualization

## 📈 Key Insights

The dashboard highlights important patterns in customer churn and helps identify customer groups that require greater retention focus.

## 💡 Recommendations

- Focus retention efforts on high-risk customer segments.
- Monitor customers with shorter tenure.
- Analyze contract and payment patterns associated with higher churn.
- Use customer behavior insights to develop targeted retention strategies.
